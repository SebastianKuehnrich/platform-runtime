Elements-Tab

Zeigt den DOM-Tree links und CSS-Regeln rechts. Hier siehst du geschriebene Regeln — nicht die berechneten Werte.

Selektiere ein Element im DOM, und rechts erscheinen alle CSS-Regeln, die es matchen, sortiert nach Specificity.

Tipp: Durchgestrichene Regeln wurden von einer staerkeren Regel ueberschrieben.

Computed-Tab — Der Senior-Move

Zeigt den finalen berechneten Wert jeder CSS-Property. Nicht die Regel — den Wert.

Beispiel: .plan auf der Pricing-Page:

padding32px.plan { padding: 2rem }
background-colorrgb(255, 255, 255).plan { background: var(--color-card) }
border-colorrgb(226, 232, 240).plan { border: 1px solid var(--color-border) }
border-radius12px.plan { border-radius: var(--radius-card) }
box-sizingborder-box* { box-sizing: border-box }

Layout-Tab

Zeigt Grid- und Flexbox-Overlays. Klicke auf einen Grid-Container und aktiviere "Show grid".

Die Pricing-Grid zeigt dir die Subgrid-Rows: grid-template-rows: subgrid auf .plan.

Tipp: Die farbigen Overlays zeigen Grid-Lines und Gap-Bereiche direkt auf der Page.

Network-Tab

Zeigt jeden HTTP-Request: CSS-Files, Bilder, Fonts, API-Calls.

Wenn ein CSS-File 404 wirft, siehst du es hier in rot. Filter nach "CSS" um nur Stylesheets zu sehen.

Console-Tab

Fuer @supports-Tests: CSS.supports('anchor-name', '--test') gibt true/false.

Zeigt auch JavaScript-Errors und Framework-Logs.

Quick Quiz — "Wo wuerdest du nachschauen?"

Dein var(--color-muted) zeigt die falsche Farbe. Wo schaust du nach?

Computed-Tab zeigt den tatsaechlich berechneten Farbwert — nicht die Variable, sondern das Ergebnis.

Dein CSS-File scheint nicht geladen zu werden. Wo checkst du das?

Network-Tab zeigt HTTP-Status-Codes. Ein 404 bedeutet: File nicht gefunden.

Die Pricing-Cards sind vertikal nicht aligned. Wo debuggst du das Grid?

Layout-Tab zeigt Grid-Overlays und Subgrid-Rows direkt auf der Page.
